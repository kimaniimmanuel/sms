# @sms/desktop

Electron + React desktop client (admin-facing). **Placeholder — fleshed out in Epic E13.**

Stack target:

- Electron (main + preload)
- Vite + React 18 renderer
- React Router for navigation
- Local SQLite via better-sqlite3 (or PowerSync's SQLite adapter)
- Standalone mode toggle (P1) for cloud-disconnected operation

Planned screens: login, dashboard, students, users, access log, settings.
